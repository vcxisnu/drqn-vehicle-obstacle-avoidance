## 环境
- N×N 栅格（默认 10；主实验在 10×10 上训练；15×15 / 20×20 既做了零样本迁移评估，也做了同尺寸重新训练，见“补充实验一/二”）；每回合随机障碍（`--density`），随机起终点；BFS 检查不可达则重新生成。
- **最小起终点曼哈顿距离** `--min_dist`：默认 7（= 最大窗口边长，≥ 所有 k）。故意不随 k 变化，使 3/5/7 三种窗口**使用完全相同的地图分布和测试集**。
- 动作：0 上 / 1 下 / 2 左 / 3 右。
- **状态** = k×k 局部窗口展平（障碍通道，越界视为障碍）+ k×k 目标通道（目标在视野内时为 1）+ 目标偏移 (行偏移, 列偏移)/(N−1)。向量长度 2k²+2。不含全局地图。
  - 注：除障碍外额外加了一个“目标是否在窗口内”的通道；若论文要求严格只用障碍窗口，可在 `_obs()` 中去掉（偏移量已能推出目标位置）。
  - **可选** `--obs_mode los`：同一向量长度。地图内被挡住的格子记为 −1（不论真实空地或障碍），射线上第一面障碍仍为 1，越界仍为 1。目标通道只在目标格可见时为 1；偏移始终是真实偏移。默认 `window` 与上面这段逐格相同。规格、拐角/边界策略和“下表不是遮挡结果”见 `docs/los-occlusion.md`。
- **奖励**（`RewardConfig`）：
  - 塑形（**严格势函数形式**，Ng, Harada & Russell 1999）：`F = 0.1 × (γ·Φ(s') − Φ(s))`，`Φ(s) = −d_BFS(s, goal)`，**γ = 0.99 与智能体折扣相同**（由 config 传入环境，`common.DEFAULT_GAMMA`）。BFS 用全局地图，**只用于计算奖励，不进入状态**。
    - 终止状态势函数取 0：到达目标时 d=0 本来就是 0；**撞障碍终止时也取 Φ(s')=0**（回合制任务中保证最优策略不变的标准做法），因此碰撞步的塑形项为 `+0.1·d_BFS(s)`，碰撞步总奖励约 `−10 + 0.1·d_BFS(s)`（10×10 上 d 很少超过 25，即约 −10 到 −7.5），远差于继续找路。
    - 势函数定理（Ng 1999）针对 MDP。本设定下对任意历史依赖策略，期望回报的平移量为 `−0.1·E[Φ(s₀)]`（与策略无关）加 `0.1·E[γ^T Φ(s_T)]`；后者在终止时为 0，**在截断（超时）时依赖策略**（γ^80≈0.45，|Φ|≤约 20，偏差上限约 0.9）。只有把超时当作 bootstrap 的无限时域问题（本实现），不变性才严格成立；论文中应写出这一推理。
    - 撞边界原地不动：s'=s，塑形项为 `0.1·(γ−1)·Φ(s) = 0.001·d_BFS(s)`（很小的正数），被 −0.2 主导。
    - 超时是截断而非终止：截断那一步按正常的 Φ(s') 计算，TD 目标照常自举，与塑形一致。
    - v1（旧版）用的是 `0.1 × (d(s) − d(s'))`，即 γ=1 的势差，而智能体 γ=0.99，二者不一致；v2 已修正并**用完全相同的配置重新训练**（旧结果未放进仓库）。
    - 数值检查 `python3 check_shaping.py`：200 张地图的值迭代中 `Q*_shaped = Q*_orig − 0.1·Φ` 误差 1e-14，最优动作集合 0 处不同；两格振荡的折扣回报 ≈ 0、撞边界 ≈ −20，直接去目标 ≈ +10，**不可刷分**。（注：未折扣地看，离目标很远（d≥10）时两格振荡每步塑形平均略大于 0，但其折扣总和有上界 −0.1·Φ(s₀)，与到达目标所得的塑形相同，不改变最优策略。）
  - 到达 +10；撞障碍 −10（terminated）；撞边界原地不动 −0.2；每步 −0.01。
  - 超时（默认 8N 步）：**truncated，无额外惩罚**，TD 目标照常自举。环境返回分开的 terminated/truncated，经验回放中也分开存储，只有 terminated 截断自举。
- **固定测试集**：第 i 张测试图由种子 `10_000_000 + i` 生成，所有方法/种子/窗口共用；训练不使用该范围。

## 网络
- DQN：输入 → FC(128) → FC(128) → **FC(w)**（w≈997，用来与 LSTM 参数量对齐）→ 4 个 Q 值
- DRQN：输入 → FC(128) → FC(128) → **LSTM(128)** → 4 个 Q 值
- 训练开始时打印参数量（k=5：DQN 155,901，DRQN 155,908）。
- ε 线性从 1.0 衰减到 0.01（前 60% 回合）；Adam lr 5e-4；batch 32；目标网络每 1000 步同步；Huber loss；Double DQN。
- DRQN 回放：按回合存储，采样长度 16 的子序列，前接最多 8 步 burn-in；burn-in 起点隐藏状态置零，burn-in 部分不计损失（梯度仍会流经 burn-in，和 R2D2 略有差异，可在论文中说明）。
  - **记忆长度上限**：训练时隐状态最多看到 burn-in + seq_len = 24 步历史，而执行时隐状态从回合开始累积（最长 80 步）。“记住走过的死胡同”这一论点只对 24 步以内严格成立，论文需说明。
  - 回合采样为均匀采样：每条转移被采到的概率 ∝ 1/回合长度，短碰撞回合被过采样（训练日志中 ≤3 步的回合占 12.8%，占转移 1.5%，却占采样步 12.8%）。这是 v2 的设置，保留不变，论文局限中可提一句。

### 统计方法
- 表中 CI：5 个种子的成功率均值 ± t₀.₉₇₅,₄·s/√5；训练曲线阴影用同一 t 分布 CI。
- 显著性（`aggregate.py`）：比较 DQN k5 vs DRQN k5、DRQN k3 vs k5、k5 vs k7、k3 vs k7，整体及简单/中等/困难各组：
  - **多重比较**：主假设族 = 配置间比较 × 贪心评估 × overall 组，对该族做 **Holm 校正**（`significance.csv` 的 `holm_p` 列，`family=primary`）；难度分组、ε-贪心评估等为**探索性分析**，报告未校正 p 值。
  - 措辞：p ≥ 0.05 记为“未检出差异”而非“不显著/无差异”，并给出差值的 bootstrap CI（例如 k5 vs k7：差 +0.009，CI [−0.011, +0.030]，即 k7 最多可能好约 1 个百分点或差约 3 个百分点）。
  - Welch t 检验（每种子成功率，n=5 vs 5）；
  - 两层配对 bootstrap：所有配置共用同一 500 张测试图，每次重采样地图（两配置用同一组地图下标 → 配对）并各自重采样种子，10,000 次，给出成功率差的 95% CI 和双侧 p 值；
  - 同一配置 ε-贪心 vs 贪心：同一批模型，用配对 t 检验，bootstrap 中种子也配对。

### 失败标签（`failure_analysis.py`，互斥单标签，按优先级取第一个命中的）
“尾段”= 轨迹最后 min(40, T/2) 步（超时为最后 40 步）。
1. `collision` 撞障碍；2. `border_bump_stuck` 尾段 ≥80% 步原地不动（反复撞边界）；3. `dead_end_stuck` 最后 20 个位置全在死胡同口袋内（死胡同格及通向它的 1 格宽通道，直到第一个岔口）；4. `two_cell_osc` 尾段 ≥80% 步满足 pos[t]=pos[t−2]（两格来回）；5. `long_cycle` 尾段对某个周期 L∈[3,8] ≥80% 周期，或尾段内某格被访问 ≥3 次；6. `narrow_corridor` 尾段 ≥50% 位于狭窄格（≥2 个邻居被挡）；7. `u_trap` 轨迹中离目标曼哈顿最近的点，其 BFS 距离 ≥ 2×曼哈顿 + 2（目标在墙后，阈值沿用 v1，属经验阈值）；8. `dead_end_exited` 进过死胡同口袋又出来了；9. `other_timeout`。
- 另给出超时的**位置上下文**（同样互斥）：`ctx_dead_end` > `ctx_u_trap` > `ctx_narrow_corridor` > `ctx_open`；以及 `info_timeouts_strictly_periodic_pct`（尾段严格周期的超时比例）。
- 为透明起见仍输出 v1 的宽泛多标签（`oldtag_*`，可重叠）。

### 为什么要做 ε-贪心评估？
无记忆的确定性策略在**感知混叠**（不同位置看到相同的局部观测）下，会在同样的观测上永远做同样的动作，于是陷入确定性循环（最常见的是两格来回）。Singh, Jaakkola & Jordan（1994）指出，在 POMDP 中**随机的无记忆策略可以优于任何确定性无记忆策略**；少量随机性可以打破循环。DRQN 的循环状态能区分“看起来一样”的位置，因此加不加随机性几乎没有影响。
实测（新结果）：
- DQN 贪心失败中 **100%** 的超时尾段是严格周期循环（注意：确定性策略 + 确定性环境 + 有限状态下这是**必然结果**而非发现——同一位置给出同一观测、同一动作；论文中应写成“验证了理论预期”），其中两格来回占失败的 90.7%；真正有信息量的是 **DRQN 仍有 82–89% 的超时尾段严格周期**，说明 LSTM 隐状态在这些地图上收敛到了极限环；ε=0.01 / 0.05 时 DQN 超时率 0.311 → 0.244 → 0.114，确实打破了循环；但随机动作会撞障碍（碰撞率 0 → 0.058 → 0.172），**净成功率只从 0.689 升到 0.698 / 0.713（不显著，配对 t p=0.26 / 0.11）**。
- DRQN 在 ε=0.01 时只下降约 0.01（k5：0.926 → 0.914），ε=0.05 时显著下降（−0.07，主要是随机动作造成的碰撞）。
- 训练日志中 DQN 最后 1000 回合（ε=0.01）成功率 0.82–0.87（旧版 0.81–0.85），远高于冻结模型在测试集上的贪心成功率 0.63–0.79（旧版 0.46–0.64）。`diag_train_vs_eval.py` 表明这**主要不是 1% 随机动作造成的**：冻结模型 ε=0.01 只有 0.700 ± 0.080，而在同样地图上**继续在线更新**（权重每 4 步变化一次，策略在回合内是非平稳的）就达到 0.835 ± 0.014；DRQN 三种情况都约 0.90–0.92。即：训练期的高成功率来自“边学边变”的策略打破了确定性循环，而不是 ε 本身。

## 补充实验一：零样本尺寸迁移（10×10 训练 → 15×15 / 20×20 测试，不重新训练）

**做法**：直接加载 `results/runs/<config>/seed*/model.pt` 中已训练好的 20 个 10×10 模型（DQN k5、DRQN k3/k5/k7 × 5 种子），**不做任何再训练或微调**，在更大的地图上评估。随机策略仅作参考。
- 每个 N 用 500 张固定测试图，种子规则与 10×10 相同（`10_000_000 + i`），但地图在该 N 下生成（所以 N=15/20 的测试集与 10×10 不同，各方法/种子/窗口之间共用）。
- 障碍密度 0.2；**最小起终点曼哈顿距离仍为 7（不随 N 放大）**；BFS 可达性保证不变。
- **max_steps = 8N**（10×10：80，15×15：120，20×20：160）：沿用环境原有的默认规则（`8 * size`），对 N 线性放大，使“每单位边长的步数预算”与训练时一致（8N ≥ 4 × 最大曼哈顿距离 2(N−1)）。最短路平均只从 10.3（N=10）增长到 13.4（N=15）、16.6（N=20），因此预算相对更宽松，超时并非由预算不够造成。
- 评估协议与 10×10 相同：贪心（ε=0，主协议）与 ε=0.01；聚合方式相同（5 种子均值 ± 95% CI，Student t；Welch t + 两层配对 bootstrap；主假设族 = 4 个配置间比较 × 贪心 × overall，在**每个 N 内部**做 Holm 校正）。
- **N=10 的行为保持不变**：重新评估 DRQN k5 seed0 与 DQN k5 seed0（贪心与 ε=0.01）得到的 500 张图逐回合结果与仓库中已有的结果完全一致；单元测试中 10×10 测试集签名不变。

**输入分布偏移（必须在论文中说明）**：
1. 目标偏移按 `(goal − pos)/(N−1)` 归一化到 [−1, 1]（10×10 时为 /9，代码对 N 自适应）。模型训练时学到的是“1 格 = 1/9”；在 15×15 / 20×20 上 1 格 = 1/14 / 1/19。也就是说，同样相距 5 格的目标，在 20×20 上输入值只有 10×10 时的约 47%，网络“看到”的目标更近。反过来，偏移绝对值 > 9 格的情况在训练中从未出现（训练时偏移的归一化值 ±1 对应 9 格，现在对应 14 / 19 格）。这一偏移是零样本迁移本身的一部分，结果应解读为“含尺度偏移的泛化能力”，而不是纯粹的“更大地图上的能力”。
2. 局部窗口（k×k、越界视为障碍）、目标通道和奖励塑形与 N 无关；但更大地图上远离边界的格子比例更高，窗口里“越界 = 障碍”的情况更少，同样与训练分布不同。
3. 难度分组仍用 10×10 的阈值（最短路 ≤9 / 10–11 / ≥12），在大图上大部分测试图落入“困难”（N=15：易/中/难 = 109/84/307 张；N=20：71/49/380 张），分组结果只能在同一 N 内横向比较。

## 难度分组
- 按最短路径长度：简单 ≤9，中等 10–11，困难 ≥12（`--bins 9 11`，约为 10×10、密度 0.2 测试集的三分位数；换地图尺寸要重新设定）。
- 按障碍密度：用 `--density 0.1/0.2/0.3` 分别评估（`plots/density.png`）。

## 与经典规划方法的关系：A* 与 D* Lite
- **A\*** 在地图**完全已知**时能给出最短路径；本任务中智能体只看到 k×k 局部窗口，A* 不能直接使用。
- 但这**不能**作为“必须用深度强化学习”的论据：**D\* Lite**（Koenig & Likhachev, 2002）等增量重规划算法正是为**部分已知地图**设计的——把未知区域假设为可通行，边走边把观测到的障碍写入地图，并以增量方式高效重算最短路径。在本文这种静态栅格、观测无噪声的设定下，D* Lite 完全可以完成任务，而且有完备性保证。因此 README 与论文中“A* 需要完整地图，所以用 DRL”的说法应弱化。
- 本文中 DRL 的价值定位是：通过**试错**学到一个**反应式策略**（观测/记忆 → 动作），**不需要规划器，也不需要显式维护地图**；每回合随机地图和起终点，防止策略“背地图”，迫使它学到可泛化的避障规则。研究问题是“学习式策略在部分可观测下能否借助记忆（LSTM）弥补局部观测的不足”，而不是声称经典规划做不到。
- 若时间允许，可在相关工作或讨论中把 D* Lite 作为“有地图记忆的规划上界”加以讨论（本项目不新增实验）。
